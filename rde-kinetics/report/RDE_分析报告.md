# RDE 动力学参数测定

## 摘要

基于 CHI660E 电化学工作站的旋转圆盘电极（RDE）数据，测定 Fe(CN)₆³⁻/⁴⁻ 氧化还原体系的动力学参数。4 组独立操作者，Pt 盘电极（Φ=5mm）。

## 实验条件

| 参数 | 数值 |
|------|------|
| 仪器 | CHI660E 电化学工作站 |
| 技术 | Tafel Plot (RDE) |
| 工作电极 | Pt 盘电极, Φ=5mm, A=0.196 cm² |
| 参比电极 | Hg/HgO (1M KCl) |
| 对电极 | Pt 丝 |
| 电解液 | 0.01M K₄Fe(CN)₆/K₃Fe(CN)₆ + 1M KCl |
| 转速 | 500, 1000, 1500, 1800, 2000, 2500 rpm |
| 浓度范围 | 0.0002 – 0.01 mol/L |

## 分析内容

### 1. Levich 分析 → 扩散系数

| 参数 | 测量值 | 文献值 |
|------|--------|--------|
| D_O (Fe(CN)₆³⁻) | 6.55×10⁻⁶ cm²/s | 7.6×10⁻⁶ |
| D_R (Fe(CN)₆⁴⁻) | 4.15×10⁻⁶ cm²/s | 6.3×10⁻⁶ |

4 组独立测量高度一致（差异<0.5%），验证了实验方案的可复现性。

### 2. K-L + Tafel 分析

| 操作者 | Tafel b (mV/dec) | α | R² |
|--------|-----------------|-----|------|
| Grp1 | 60.2 | 0.98 | 0.985 |
| Grp2 | 81.6 | 0.72 | 0.861 |
| Grp3 | 81.8 | 0.72 | 0.987 |
| Grp4 | 62.2 | 0.95 | 0.997 |

α 偏离理想可逆值 0.5（对应 b=118 mV/dec），归因于准可逆体系在低过电位区反反应贡献。

### 3. 半波电位

0.0008M 无 KCl：E₀ ≈ 0.161 V，E₁/₂ ≈ 0.172 V。

## 局限

- D_R 偏低 34%：阳极极限电流平台不完整
- α 偏高：过电位选区偏低，反反应贡献
- 4 组数据大部分转速下一致（CHI660E 导出精度）
